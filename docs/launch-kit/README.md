# 이든의 퍼즐 — 실제 앱 스크린샷

v55 실제 웹 UI를 캡처한 PNG 4장입니다. 바깥 배경, 홍보 문구, 장식 테두리, 별도 여백을 제거했습니다. 앱 자체의 배경과 UI는 그대로입니다. 각 PNG는 1170 × 2532 픽셀이며, 390 × 844 모바일 화면을 브라우저에서 3배로 렌더링했습니다. 앱스토어에 제출한 상태는 아닙니다.

## 이미지별 기능 설명

1. **01-playground.png** — 놀이터 홈. 상단 토글로 작업실로 바꾸고, 상상놀이·동화·명화·세계여행에서 그림을 고릅니다.
2. **02-studio.png** — 작업실 홈. 고흐·모네 등 작가별 컬렉션에서 작품을 고르고 조각 수를 선택합니다.
3. **03-photo-puzzle.png** — 사진 선택 기능으로 불러온 이미지의 실제 6조각 플레이 화면입니다.
4. **04-frames.png** — 첫 완성 전의 액자 앨범입니다. 놀이터의 6·12·24·48조각 프레임 조건과 첫 액자 만들기 안내를 보여줍니다.

사진 선택 시연에는 저장소의 에펠탑 그림을 불러왔습니다. 개인 사진이나 계정은 포함하지 않았습니다. ZIP에는 위 PNG와 이 설명 파일이 함께 들어 있습니다.

## 재촬영

저장소를 로컬 웹 서버로 열고 `/docs/launch-kit/index.html`에 접속합니다. 브라우저 뷰포트는 1170 × 2532로 설정합니다. 삽입된 앱에서 모드와 기능을 실제로 선택하고, 화면 전환 애니메이션이 끝난 다음 전체 페이지를 PNG로 캡처합니다. 이 페이지는 앱 화면만 렌더링하며, 별도 문구나 배경을 덧붙이지 않습니다. 촬영 후 브라우저 뷰포트를 복원합니다.

앱스토어 최종 제출 시 대상 기기 규격과 네이티브 빌드 화면을 확인하세요. [Apple 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications).
