# 이든의 퍼즐 — 한국어 소개 이미지

앱 v55의 실제 웹 UI를 촬영한 소개 이미지 4장입니다. 각 PNG는 1290 × 2796 픽셀이며, 화면 위에 기능을 설명하는 짧은 문구를 배치했습니다. 앱스토어에 제출한 상태는 아닙니다.

| 파일 | 설명 |
| --- | --- |
| `png/01-playground.png` | 놀이터, 네 가지 그림 분류, 상단 테마 전환 |
| `png/02-studio.png` | 작업실, 작가별 패키지, 여유 있는 그림 선택 화면 |
| `png/03-photo-puzzle.png` | 파일에서 선택한 이미지로 진행하는 실제 퍼즐 화면 |
| `png/04-frames.png` | 완성한 그림의 액자 앨범과 난도별 프레임 보상 |

사진 퍼즐 시연에는 저장소의 에펠탑 그림을 파일 선택으로 불러왔습니다. 앨범은 로컬 테스트에서 실제로 완성한 기록입니다. 계정이나 개인 사진은 포함하지 않았습니다.

## 재촬영

저장소를 로컬 웹 서버로 열고 `/docs/launch-kit/index.html?slide=1`에 접속합니다. `slide` 값은 1–4입니다. 브라우저 뷰포트를 1290 × 2796으로 설정하고, 삽입된 앱에서 해당 모드·화면을 실제로 선택한 뒤 전체 페이지를 PNG로 캡처합니다. 화면의 상태는 해당 브라우저의 로컬 기록을 사용하므로 자동으로 연출되지 않습니다.

공식 크기 참고: [Apple 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications). 최종 제출 시 대상 기기별 요구사항과 네이티브 빌드의 실제 화면을 확인하세요.

## UI 검증

놀이터·작업실을 각각 320 × 568, 390 × 844, 768 × 1024, 1024 × 768에서 확인했습니다. 한 줄 헤더 높이 46px, 가로 넘침 없음, 주요 패널 겹침 없음. 모드별 프레임 단계와 성경 제외, 코인 이전 및 완료 기록은 `node tests/progression.cjs`로 검증합니다.
